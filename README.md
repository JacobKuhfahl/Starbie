# Starbie

Starbie is a small environmental sensor project designed to measure temperature, humidity, and motion.

## How It Works

Starbie uses an MPU6050 motion sensor and a DHT11 temperature/humidity sensor to collect environmental and movement data.

The sensors connect to a microcontroller, which reads the sensor data and can use it for the Starbie project.

## Main Components

- Microcontroller
- MPU6050 motion sensor
- DHT11 temperature/humidity sensor
- Custom PCB

## Project Status

This project is currently being developed.
